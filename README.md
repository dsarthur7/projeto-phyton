# Lista de Tarefas — Python

Projeto simples em Python puro (sem framework nenhum) pra praticar lógica de
programação e treinar Git/GitHub.

É uma lista de tarefas que roda no terminal. Dá pra adicionar tarefa, marcar como
concluída, desmarcar, excluir e listar tudo. As tarefas ficam salvas num arquivo de
texto (`tarefas.txt`), então não se perdem quando você fecha o programa.

## Tecnologias
- Python (só a biblioteca padrão, nada instalado)

## Como rodar
1. Tenha o Python instalado
2. Rode: `python tarefas.py`
3. Use o menu que aparece no terminal

## Sobre
Fiz esse projeto pra um trabalho da faculdade sobre Git e GitHub, aplicando na prática
o que aprendi na trilha GitHub Foundations. Usei só o básico de Python que já sei:
listas, laços, condicionais e leitura/escrita de arquivo.
