# Lista de Tarefas — Python

Projeto simples em Python para praticar lógica de
programação e treinar GitHub.

É uma lista de tarefas que roda no terminal. Dá pra adicionar tarefa, marcar como
concluída, desmarcar, excluir e listar tudo.

## Sobre
Fiz esse projeto pra um trabalho da faculdade sobre Git e GitHub, aplicando na prática
o que aprendi na trilha GitHub Foundations.
